## Weizäcker Formel (semi empirical mass formula)

$$
\begin{aligned}
M(A, Z)= & N M_{\mathrm{n}}+Z M_{\mathrm{p}}+Z m_{\mathrm{e}}-a_{\mathrm{v}} A+a_{\mathrm{s}} A^{2 / 3} \\
& +a_{\mathrm{c}} \frac{Z^{2}}{A^{1 / 3}}+a_{\mathrm{a}} \frac{(N-Z)^{2}}{4 A}+\frac{\delta}{A^{1 / 2}}
\end{aligned}
$$

\begin{aligned}
a_{\mathrm{v}} & =15.67 \mathrm{MeV} / c^{2} \\
a_{\mathrm{s}} & =17.23 \mathrm{MeV} / c^{2} \\
a_{\mathrm{c}} & =0.714 \mathrm{MeV} / c^{2} \\
a_{\mathrm{a}} & =93.15 \mathrm{MeV} / c^{2} \\
\delta & =\left\{\begin{aligned}
-11.2 \mathrm{MeV} / c^{2} & \text { falls } Z \text { und } N \text { gerade sind (gg-Kerne) } \\
0 \mathrm{MeV} / c^{2} & \text { falls } A \text { ungerade ist (ug-Kerne) } \\
+11.2 \mathrm{MeV} / c^{2} & \text { falls } Z \text { und } N \text { ungerade sind (uu-Kerne). }
\end{aligned}\right.
\end{aligned}
