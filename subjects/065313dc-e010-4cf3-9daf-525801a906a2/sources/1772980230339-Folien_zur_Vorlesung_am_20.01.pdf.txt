## 10. Phasenübergänge

### 10.1 Phänomenologie und Begriffe

Phasen: Zustände der Materie, die sich durch thermische, mechanische, magnetische, etc. Eigenschaften sowie durch ihre Symmetrien unterscheiden.

> Innerhalb einer Phase sind thermodynamische Potentiale analytische Funktionen der Zustandsvariablen.

Phasenübergang: Änderung der Phase bei Änderung eines Parameters. In der Nähe des Übergangs ist die freie Energie (oder ein anderes therm. Potential) eine nicht-analytische Funktion (nicht beliebig oft differenzierbar).

## Einschub: Ergänzungen zur Thermodynamik

## A) Clausius-Clapeyron-Gleichung

Beim Flüssigkeit-Gas Übergang gilt entlang der Phasenkoexistenzkurve:

\mu_{\mathrm{f}}\left(p_{0}, T\right)=\mu_{\mathrm{g}}\left(p_{0}, T\right), \quad p_{0} \equiv p_{0}(T) \longleftrightarrow \text { Gleichgewichtsdruck }

Außerdem wissen wir (siehe Kapitel 2.4) :

\mu(p, T)=\frac{G(p, T)}{N} \quad \text { und } \quad S=-\left.\frac{\partial G}{\partial T}\right|_{p}, \quad V=\left.\frac{\partial G}{\partial p}\right|_{T}

Daraus folgt: $\begin{aligned} \frac{d}{d T} \mu_{\mathrm{f}}\left(p_{0}(T), T\right) & =\frac{\partial \mu_{\mathrm{f}}}{\partial p} \frac{\partial p_{0}}{\partial T}+\frac{\partial \mu_{\mathrm{f}}}{\partial T}= \\ \underset{\downarrow}{\swarrow} / N & \stackrel{\partial \mu_{\mathrm{g}}}{\partial p} \frac{\partial p_{0}}{\partial T}+\frac{\partial \mu_{\mathrm{g}}}{\partial T} \\ V_{\mathrm{f}} / N & \stackrel{\downarrow}{\mathrm{f}} / N\end{aligned} \underset{\stackrel{\downarrow}{\mathrm{~g}} / N}{\downarrow} S_{\mathrm{g} / N}$
und wir erhalten die Clausius-Clapeyron-Gleichung

\frac{\partial p_{0}}{\partial T}=\frac{S_{\mathrm{g}}-S_{\mathrm{f}}}{V_{\mathrm{g}}-V_{\mathrm{f}}}=\frac{Q_{L}}{T \Delta V}

![This diagram depicts the entropy (S) as a function of temperature (T), showing a discontinuous jump in entropy (ΔS) at a critical temperature (T₀), characteristic of a first-order phase transition.](http://localhost:5001/subjects/065313dc-e010-4cf3-9daf-525801a906a2/images/0c5e62cc-98f5-492d-a706-27be6593c1e6/70b260bd-5d0e-4790-83be-d2021eaf0ec7-08_630_957_306_1817.jpg)

Näherung (ideales Gas): $V_{\mathrm{f}} \ll V_{\mathrm{g}}, V_{\mathrm{g}} \simeq N k_{B} T / p, q_{L}=Q_{L} / N$

\frac{d p_{0}}{p_{0}}=\frac{q_{L}}{k_{B} T^{2}} d T \quad \Rightarrow \quad p_{0}(T)=C e^{-q_{L} /\left(k_{B} T\right)}

### 10.1.2 Symmetriebrechung und Ordnungsparameter

Bei den meisten Phasenübergängen wird eine Symmetrie des Systems spontan gebrochen. Dabei geht das System von einem ungeordneten Zustand mit hoher Symmetrie in einen geordneten Zustand mit niedrigerer Symmetrie über

| Phase | gebrochene Symmetrie |
| :--- | :--- |
| Kristall | Translationssymmetrie |
| Ferromagnet | Rotationssymmetrie |
| Ising-Ferromagnet | Inversionssymmetrie |
| Supraleiter | Eichsymmetrie (global Phasenrotation) |

-Phase bei hoher Temperatur ist in der Regel ungeordnete Phase mit höherer Symmetrie.

- Ausnahmen zur Symmetriebrechung: z.B. Gas -> Flüssigkeit


## "Ordnungsparameter":

Makroskopische Zustandsvariable, die in der ungeordneten Phase verschwindet, aber in der geordneten Phase einen endlichen Wert annimmt.

| Phase | Ordnungsparameter $\varphi$ |
| :--- | :--- |
| Ferromagnet | Magnetisierung $\overrightarrow{\mathcal{M}}$ (Vektor) |
| Ising-Ferromagnet | Ising-Magnetisierung $m$ (Skalar) |
| Flüssigkeit | Dichtedifferenz $\Delta n=n_{\mathrm{f}}-n_{\mathrm{g}} \quad$ (Skalar) |
| Suprafluides He | Grundzustandswellenfunktion $\Psi_{0}$ (komplex) |
| Supraleiter | Energielücke $\Delta$ (Skalar) <br> Cooper-Paar-Wellenfunktion $\Psi_{s}$ (komplex) |
|  |  |

- bei Symmetriebrechung -> Ordnungsparameter als zusätzlicher Parameter zur Beschreibung des Systems notwendig
- allgemein keine systematische Methode, den Ordnungsparameter einer Phase zu identifizieren


### 10.2 Kritische Phänomene

Das Verhalten eines Systems in der Nähe des kritischen Punkts hängt nicht von mikroskopischen Details ab und wird durch wenige kritische Exponenten beschrieben.

### 10.2.1 Kritische Exponenten

Die kritischen Exponenten $\alpha, \beta, \gamma$ und $\delta$ beschreiben das Verhalten therm. Größen in der Umgebung eines Phasenübergangs 2. Ordnung:

|  | mag. System | Gas/Flüssigkeit |
| :--- | :---: | :---: |
| spez. Wärme | $C_{B} \sim\|\tau\|^{-\alpha}$ | $C_{T} \sim\|\tau\|^{-\alpha}$ |
| Ordnungsparameter | $m \sim\|\tau\|^{\beta}$ | $\delta v \sim\|\tau\|^{\beta}$ |
| Response-Funktion | $\chi \sim\|\tau\|^{-\gamma}$ | $\kappa_{T} \sim\|\tau\|^{-\gamma}$ |
| Zustandsgleichung $(\tau=0)$ | $B \sim m^{\delta}$ | $\delta p \sim \delta v^{\delta}$ |

wobei:

\tau=\left(T-T_{c}\right) / T_{c}

## Bemerkungen:

- Divergentes Verhalten meist symmetrisch um $\mathrm{T}=\mathrm{T}_{\mathrm{c}}$.
- Ausnahme: Ordnungsparameter, da $m=0$ für $\mathrm{T}>\mathrm{T}_{\mathrm{c}}$.
- allgemeine Definition der kritischen Exponenten: $\alpha=\lim _{\tau \rightarrow 0^{+}} \frac{\ln f(\tau)}{\ln \tau}$

Damit erhält man $\alpha=0$ für Sprung in der Funktion $f(\tau)$ oder auch für logarithmische Divergenz, $f(\tau) \sim-\ln (|\tau|)$.

## Korrelationen:

Weiters führt man 2 weitere Exponenten $\eta$ und $\nu$ zur Beschreibung räumlicher Korrelationen ein.

Man findet $\left(\mathrm{T} \sim \mathrm{T}_{\mathrm{c}}\right): \quad G(\vec{r})=\langle\varphi(\vec{r}) \varphi(0)\rangle-\langle\varphi(\vec{r})\rangle\langle\varphi(0)\rangle \quad \sim \frac{e^{-|\vec{r}| / \xi}}{|\vec{r}|^{p}}$

- Korrelationslänge: $\quad \xi \sim|\tau|^{\nu} \longrightarrow \infty$
- Potenzgesetz bei $\mathrm{T}=\mathrm{T}_{\mathrm{c}}: \quad p=d-2+\eta \quad d \ldots$ Dimension


### 10.2.2 Universalität:

Die kritischen Exponenten sind universell, d.h. sie hängen nicht von mikroskopischen Details des Systems sondern nur von

1. der Dimension d des Systems
2. der Reichweite der Wechselwirkung
3. der Anzahl der Komponenten/Symmetrie des Ordnungsparameters ab .

⇒ "Universalitätsklasse": Alle Phasenübergänge mit gleichen kritischen Exponenten.

| Universalitätsklasse | $\alpha$ | $\beta$ | $\gamma$ | $\delta$ | $\nu$ | $\eta$ |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| MF-Theorien | $0(\operatorname{disk})$ | $1 / 2$ | 1 | 3 | $1 / 2$ | 0 |
| 2D Ising | $0(\log )$ | $1 / 8$ | $7 / 4$ | 15 | 1 | $1 / 4$ |
| 3D Ising | 0.11 | 0.33 | 1.24 | 4.82 | 0.63 | 0.03 |
| Potts (2D,q=3) | $1 / 3$ | $1 / 9$ | $13 / 9$ | 14 | $5 / 6$ | $4 / 15$ |

## Bemerkungen:

-) Exakte Lösung des 1D Ising Modells mit transversalem Feld bei $\mathrm{T}=0$ :

\beta=1 / 8, \nu=1, \eta=1 / 4, \ldots \quad \Leftrightarrow \quad \begin{array}{r}
\text { Universalitätsklasse: } \\
\text { 2D Ising Modell }
\end{array}

-) allgemein: Korrespondenz zwischen d-dim. Quantenphasenübergang $(\mathrm{T}=0)$ und Phasenübergang in $(\mathrm{d}+1)$-dim. klassischen Modell.
-) Skalierungsrelationen (ohne Beweis):

\begin{array}{cl}
\alpha+2 \beta+\gamma=2 & 2-\alpha=d \nu \\
\gamma=\beta(\delta-1) & \gamma=\nu(2-\eta)
\end{array}

### 10.3 Landau Theorie

- erste allgemeine (phänomenologische) Theorie von Phasenübergängen (2.Ordnung)
- wichtigste Anwendung: Beschreibung der Eigenschaften von Supraleitern (Ginzburg, Landau 1950) (noch ohne mikroskopisches Modell)


## Grundlegende Annahmen:

1) Der PÜ zwischen einer ungeordneten und einer geordneter Phase wird durch den Ordnungsparameter $\varphi$, bzw. durch dessen i. A. ortsabhängige Dichte $\psi(\vec{r})$ beschrieben:

\varphi=\int d^{3} r \psi(\vec{r}), \quad \psi(\vec{r}) \begin{cases}=0 & T>T_{c} \\ \neq 0 & T<T_{c}\end{cases}

2) In der Nähe des PÜ ist $\psi(\vec{r})$ klein und die freie Energie kann in Potenzen von $\psi(\vec{r})$ und $\nabla \psi(\vec{r})$ entwickelt werden:

\begin{gathered}
F(T ; \varphi)=F_{0}(T)+\int d^{3} r\left[-\pi(\vec{r}) \psi(\vec{r})+a(T) \psi^{2}(\vec{r})+b(T) \psi^{4}(\vec{r})\right. \\
\left.+c(T)(\nabla \psi(\vec{r}))^{2}+\ldots\right]
\end{gathered}

## Diskussion:

- $\pi(\vec{r})$ : die zum Ordnungsparameter konjugierte Kraft / externes Feld: z.B. homogenes Magnetfeld:

\pi(\vec{r}) \equiv \mu B, \quad \psi(\vec{r}) \equiv \mathcal{M} \quad \varphi=-\frac{\partial F}{\partial \pi} \Leftrightarrow \mathcal{M}=-\frac{\partial F}{\partial B}

Achtung: Ankopplung an externes Feld ⟶ explizite Symmetriebrechung!

- Für $\pi(\vec{r})=0$ muss die freie Energie invariant unter Symmetrietransformationen sein!

\text { z.B. } \quad F(T, \varphi)=F(T,-\varphi) \quad \Rightarrow \quad \begin{aligned}
& \text { keine ungeraden Potenzen } \\
& \text { von } \psi(\vec{r}), \nabla \psi(\vec{r}) \text { erlaubt! }
\end{aligned}

- Allgemeiner Ordnungsparameter: $\psi(\vec{r}) \in \mathbb{C}, \vec{\psi}(\vec{r}) \in \mathbb{R}^{n}, \ldots$

\psi^{2}(\vec{r}) \rightarrow|\psi(\vec{r})|^{2}, \vec{\psi} \cdot \vec{\psi}, \ldots \in \mathbb{R} \quad \begin{aligned}
& \text { invariant unter Rotationen, } \\
& \text { Eichtransformationen, etc. }
\end{aligned}

### 10.3.1 Phasenübergänge 2. Ordnung

## homogenes System:

F(T ; \varphi) \simeq F_{0}(T)-\pi \varphi+a(T) \varphi^{2}+b(T) \varphi^{4}+\ldots

- Im Gleichgewichtszustand ist die freie Energie minimal, d.h.:

\frac{\partial F}{\partial \varphi}=0, \quad \frac{\partial^{2} F}{\partial \varphi^{2}}>0, \quad b(T)>0

\begin{array}{ll}
\Rightarrow & 2 a(T) \varphi+4 b(T) \varphi^{3}=\pi \\
\Rightarrow & 2 a(T)+12 b(T) \varphi^{2}>0

Existenz eines globalen Minimums

- Für $\pi=0$ (ohne externe Symmetriebrechung) ergeben sich damit zwei verschiedene stabile Lösungen:
$(\mathbf{I}) a(T)>0$ :

\varphi=0

( → ungeordnete Phase, $\mathrm{T}>\mathrm{T}_{\mathrm{c}}$ )
(II) $a(T)<0$ :

\varphi= \pm \sqrt{\frac{-a(T)}{2 b(T)}}

( → geordnete Phase, $\mathrm{T}<\mathrm{T}_{\mathrm{c}}$ )

Um einen Übergang von einer ungeordneten zu einer geordneten Phase zu erhalten, muss $a(T)$ bei $\mathrm{T}=\mathrm{T}_{\mathrm{c}}$ das Vorzeichen wechseln.
